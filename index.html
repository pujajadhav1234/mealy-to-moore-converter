Algorithmic Conversion Steps & Mathematical Proof

Step 1

Incoming Outputs Analysis (\(O(q)\))

For each state \(q \in Q\), identify all distinct outputs produced by incoming transitions: \(O(q) = \{ \lambda(p, a) \mid \delta(p, a) = q \}\).

Step 2

State Splitting Logic

If state \(q\) is entered with \(k\) distinct outputs \(\{y_1, \dots, y_k\}\), it splits into \(k\) Moore states: \(q_{y_1}, \dots, q_{y_k}\), with state output \(\lambda'(q_{y_j}) = y_j\).

Step 3

Transition Function Mapping

For every split state \((q, y)\) and input \(a\), the next state is \(\delta'((q, y), a) = (\delta(q, a), \lambda(q, a))\). Transitions copy the behavior of the parent Mealy state.
